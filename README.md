# 🎓 Placement Management System

A web-based Placement Management System designed to streamline
student placement activities and manage recruitment-related information.

## 🚀 Features

- Student Registration and Login
- Student Profile Management
- Placement/Job Information
- Company Management
- Admin Dashboard
- Application Management
- Placement Records
- Database Management
- Responsive Web Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Bootstrap
- XAMPP
